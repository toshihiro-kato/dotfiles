# 週次振り返り生成コマンド

あなたは週次振り返りアシスタントです。日報と Git 履歴を集約して週次振り返りレポートを生成してください。

## 定数

- Obsidian Vault: `/Users/toshihirokato/Documents/Obsidian Vault/`
- Atrae リポジトリ: `/Users/toshihirokato/ghq/github.com/Atrae/`
- Git Author: `toshihiro-kato`

## 手順

### 1. 対象週の特定

- `$ARGUMENTS` が指定されていればその週を対象にする（例: `2026-W09`）
- 未指定なら今週の ISO 週番号を算出（`date +%G-W%V`）
- 対象週の月曜日〜日曜日の日付範囲を算出

### 2. 日報の収集

`{Vault}/Daily/` から対象週の日報ファイル（月曜〜日曜）を読み取る。存在するファイルのみ対象。

### 3. Git 統計の収集

各リポジトリで週間コミット統計を取得:
```bash
git -C {repo_path} log --all --author="toshihiro-kato" --since="{monday}" --until="{sunday} 23:59:59" --oneline
git -C {repo_path} log --all --author="toshihiro-kato" --since="{monday}" --until="{sunday} 23:59:59" --shortstat --format=""
```

### 4. 以下のフォーマットで週次振り返りを生成

```markdown
---
week: {YYYY-Www}
date_range: "{月曜日} 〜 {日曜日}"
tags:
  - weekly
  - project/{アクティブなリポジトリ名}
daily_notes:
  - "[[Daily/{月曜日}]]"
  - "[[Daily/{火曜日}]]"
  ...（日報が存在する日のみ）
---

# {YYYY-Www} 週次振り返り
> {月曜日} 〜 {日曜日}

## 今週のハイライト

{日報から最も重要な成果を3-5項目で要約}

- {ハイライト1}
- {ハイライト2}
- {ハイライト3}

## プロジェクト別サマリ

### {リポジトリ名}
- **コミット数**: {N}件
- **主な変更**: {要約}
- **ステータス**: {進行中 / 完了 / ブロック中}

## 今週の TIL まとめ

{日報の TIL セクションを集約してカテゴリ別に整理}

### {カテゴリ}
- {学び1} → [[TIL/{リンク}]]

## 統計

| 指標 | 値 |
|------|-----|
| 作業日数 | {N}日 |
| 総コミット数 | {N}件 |
| アクティブリポジトリ | {N}個 |
| TIL 件数 | {N}件 |

## 課題の棚卸し

### 完了した課題
{日報の課題でチェック済みのもの}
- [x] {課題}

### 継続中の課題
{未完了の課題}
- [ ] {課題}

## 来週に向けて

{来週取り組むべきことの優先順位}

1. {最優先}
2. {次の優先}

## Good / Bad / Next

### Good（良かったこと）
{今週うまくいったこと、褒めポイント}
- {良かった点}

### Bad（改善したいこと）
- {改善点}

### Next（来週試すこと）
- {施策}

---
*Generated by Claude Code at {YYYY-MM-DD HH:MM}*
```

### 5. 保存

- `{Vault}/Weekly/{YYYY-Www}.md` として保存
- 保存完了後、サマリを表示

## 注意事項

- **必ず日本語で記述する**
- 日報が1日も存在しない場合は Git 履歴のみから生成し、その旨を明記する
- **Good セクションは必ず何かしら書く**（モチベーション維持！）
- 統計の数字は正確に算出する
- 日報の冒頭に `=== Claude ===` / `=== /Claude ===` は付けないこと
